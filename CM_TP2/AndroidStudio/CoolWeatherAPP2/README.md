Cool Weather App
Description

Cool Weather App is an Android application developed in Kotlin that displays real-time weather information for a selected location using the Open-Meteo API.

The application provides:

Latitude and longitude coordinates
Temperature
Sea level pressure
Wind speed
Wind direction
Date and time of the weather data
Weather condition icon
Custom background image

By default, the application displays weather information for Lisbon (Portugal). Users can update the location coordinates and retrieve weather data for other locations.

Technologies
Android Studio
Kotlin
Open-Meteo API
Gson
XML Layouts
Features
Real-time weather information
Custom user interface
Portrait and landscape layouts
Internet API integration
Weather condition visualization
