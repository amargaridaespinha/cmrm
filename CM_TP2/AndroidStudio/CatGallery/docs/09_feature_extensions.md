# Feature Extensions

## Loading Indicator

A ProgressBar was added to show when the app is loading images from the API.

## Refresh Button

A Refresh button was added to allow the user to load a new set of cat images.

## MVVM Structure

The app uses a simple MVVM structure with MainActivity, MainViewModel, CatRepository, and CatApiService.
